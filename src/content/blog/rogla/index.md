From 17.08 until 23.08, I'll be training at the Rogla ski resort, which is at an altitude of around 1450m, together with the rest of the long-distance team from AK Kvarner and also some professional triathlon athletes from Rijeka and other places. I plan to use this as some sort of training diary or note-taking, whatever sounds like I pretend to be a wannabe pro. 

### Monday 17.08.2026

We arrived at the ski resort at around 12PM, so we just had lunch and waited for the evening session.

#### Evening session @ 5pm:

2k warm-up + 10k middle pace (\~3:45 min/km) + 1k cooldown

-  It should've been 12k, but due to my stupid decision to run a long run the night before, I was a bit heavy

### Tuesday, 18.08.2026

#### Morning session @ 10 am:

45min easy run along the nature sites at Rogla with some additional dynamic exercises, drills, and sprints. 

#### Evening session @ 5pm:

3,5k warm-up, drills and sprints,  2x10x400m@3:05 with 35s rest and 2min rest between sets, 2k cooldown

### Wednesday, 19.08.2026

#### Morning session @ 10 am:

65min easy run with a segment of 1,6k with an average 10% hill climb (search on Strava MASINZAGA segment, litterally an uphill segment over the ski lane) + additional dynamic exercises, drills, and sprints. 

#### Evening session @ 5pm:

10k easy run + drills, and afterwards some swimming exercises and sauna

### Thursday, 20.08.2026

#### Morning session @ 10 am:

18k hilly tempo run with 2k cooldown. This shit was brutally hard; first tempo downhill for 9k was fine, but my legs were still kinda sluggish in the morning, and the uphill 9k at the end was the hardest thing I've done in a long time, at least that's how it felt.

#### Evening session @ 5pm:

40min easy run with drills, sprints, and plenty of exercises using the hurdles.

### Friday, 21.08.2026

#### Morning session @ 10 am:

45min easy run with another MASINZAGA segment.

#### Evening session @ 5pm:

20min easy run and some drills just to break the sluggishness.

### Saturday, 22.08.2026

#### Morning session @ 10 am:

20min warm up, 6x1k@3:15 with 90s rest + 3x400@2:40 with 60s rest + 3x300@2:30 with 60s rest. At the end 1,6k cooldown. This was supposed to be 10x1k, but the altitude got the better of me for those distances, so I had to resort to shorter ones, which felt better.

#### Evening session @ 5pm:

45min easy run as a recovery

### Sunday, 23.08.2026

#### Morning session @ 10 am:

Last day, so we only had a morning session. This ended up as a 2-hour easy run, also around the nature of Rogla ski resort, which is as beautiful as one might think.

### Summary

In the end, one week of altitude training camp with the following conclusion:

- Total distance: 150,16k
- Total elevation gain: 1,811m
- Total running time: 12h 22m

I would say that's pretty solid for me; looking back just a few years ago, I was mainly focusing on 400m and 800m, for which I wasn't doing this much volume. Now that my focus is expanding to both middle- and long-distance events, I feel more comfortable with longer runs mixed with a few short but intense sessions.
